## สั่ง export

```bash
openscad -D 'part="fit_coupon"' -o fit_coupon.stl airguard_box.scad   # พิมพ์ได้เลย
openscad -D 'part="fit_lid"'    -o fit_lid.stl    airguard_box.scad   # พิมพ์ได้เลย
openscad -D 'part="fit_pms"'    -o fit_pms.stl    airguard_box.scad   # พิมพ์ได้เลย
openscad -D 'part="fit_oled"'   -o fit_oled.stl   airguard_box.scad   # พิมพ์ได้เลย (มิติจอยังเป็นค่าประมาณ — ชิ้นนี้ใช้เช็ค)
openscad -D 'part="body"' -o body.stl airguard_box.scad               # หลังธงครบ
openscad -D 'part="lid"'  -o lid.stl  airguard_box.scad               # (คว่ำไว้แล้ว)
openscad -D 'part="pegs"' -o pegs.stl airguard_box.scad
openscad -D 'part="sled"' -o sled.stl airguard_box.scad               # sd_mode="sled" เท่านั้น
# แบบหลุม SD ในกล่อง: เติม -D 'sd_mode="integrated"'
```

## OLED (เพิ่ม 23 ต.ค. 2569)

เจ้าของแจ้ง 23 ต.ค. ว่าจะใช้ OLED แล้ว (เปลี่ยนจากข้อตัดสินใจ 9 ต.ค. ที่ไม่ใช้) · ตั้ง `use_oled = false` ถ้าจะกลับไปใช้แบบไม่มีจอ

- **ตำแหน่ง:** ใต้ฝา เหนือหลุม PMS จอหันขึ้น อ่านจากด้านหน้า ขอบหัวขาอยู่ฝั่งหลัง · ใต้ฝาเหนือ PMS ว่าง 20 mm (ที่อื่นเหลือ 8.7–10.6) · อยู่นอกห้อง T/RH (มีผนังสองชั้นกั้น) · ห่างเสาอากาศ 96 mm
- **ทำไมไม่ใช้ผนังหน้า:** เหนือ PMS เหลือสูง 20 mm แต่ PCB จอสูง ~27.8 · ฝั่ง carrier ห่างผนังในแค่ 2 mm
- **การยึด:** กรอบห้อยจากฝา + แผ่นรอง 4 มุม (นอกกระจก ฝาไม่กดกระจก) + ลิ้นสแนปซ้าย/ขวา ปากเอียง 45° → ฝาพิมพ์คว่ำได้โดยไม่ต้องใช้ support
- **หน้าต่างบนฝา:** 23.53 × 13.25 mm (พื้นที่พิกเซลที่วัด + เผื่อข้างละ 1.0) ผายออก 45° · เยื้องเข้าหาขา 1.7 mm ตามพิกเซล · เหลือขอบกระจกบังรอบหน้าต่าง ≥ 1.16
- **ซี่กด PMS ย้าย:** จากกลางตัว PMS → ครึ่งหลัง 2 ซี่ + หน้าขวา 1 ซี่ (ไม่ชนกรอบจอ) · ตัวอักษร "AirGuard" เลื่อนไปอยู่ระหว่างจอกับผนังกั้น
- **สาย:** ขา header ตรงยื่นหลัง PCB 8.26 · ใต้จอถึงยอด PMS มี 16.62 → ห้ามเสียบหัว dupont ตรง (~21.5) · บัดกรีสายที่ปลายขา (แนะนำ) หรือดัดขา 90° · `oled_back_h = 11.3` (เหลือ 5.32)
- **ตรวจแล้ว 23 ต.ค. หลังใส่ค่าวัด (OpenSCAD 2021.01 บน Windows):** lid/body/fit_oled render เป็นชิ้นเดียวปิดสนิท · `intersection()` ฝา↔กล่อง, ฝา↔จอ, กล่อง↔ถาด = ปริมาตร 0 (แค่ผิวสัมผัส) · กล่อง↔จอ, จอ↔PMS, ฝา↔PMS, แท่งกด↔ฝา/กล่อง, ฝา↔ถาด = ว่าง · console ไม่มี `!!`
- `enclosure_v2_viewer.html`, `fit_oled.stl` และ `preview_*.png` อัปเดตตามค่าวัดแล้ว 23 ต.ค.

## ตรวจแล้ว (17 ต.ค. ในคอนเทนเนอร์ OpenSCAD 2021.01)

- ทุกชิ้น render ได้และเป็นเมช**ปิดสนิท** (watertight) — body/lid/sled เป็นชิ้นเดียว · pegs 3 ชิ้น · fit_lid 2 ชิ้น (มุมกล่อง + มุมฝา)
- **ไม่ชนกัน** ทดสอบด้วย `intersection()` 3 มิติ: กล่อง↔ฝา · กล่อง↔โมดูลทุกตัว · ฝา↔โมดูล · ถาด↔กล่อง/ฝา · แท่งกด↔กล่อง/ฝา ทั้งสองแบบ SD — เหลือแค่ผิวสัมผัส (ปริมาตร 0)
- **ไม่ต้องใช้ support**: ผิวที่หันลงเหนือฐานพิมพ์มีแค่สะพานข้ามช่อง (ช่อง USB ~29 mm · ช่องถาด SD 19 mm · ช่องลม PMS ~12 mm · ช่องลม 2 mm) และเพดานตัวอักษรแกะ
- ใต้ฝาเหลือที่: เหนือ DevKit 8.7 · เหนือ JST (ยังไม่เสียบสาย) 14.6 · เหนือ ENS 9.6 · เหนือ ZE07 10.6 mm
- บล็อกบังแสง LED และปลอกแท่งกด: เช็คกับ DXF แล้วไม่มีชิ้นสูงในกรอบ

## ยังไม่ได้ทดสอบ (ต้องพิมพ์จริง)

- ความแน่นของปากล็อก ZE07 และร่องนำ ENS · การไหลของลมจริงในห้อง T/RH
- ผลของห้อง T/RH ต่อ `temp_c`/`humidity_pct` — `[ต้องวัดจริง]` เทียบกับเทอร์โมมิเตอร์อ้างอิง ก่อนเริ่มเก็บข้อมูลเทรน
- ปริมาณเส้น/เวลาพิมพ์: ปริมาตรเนื้อ body ~79 cm³ + lid ~40 cm³ (ถ้าพิมพ์ทึบ 100%) — **ค่าคาดหมาย** เวลาจริงขึ้นกับ slicer ของคนพิมพ์
