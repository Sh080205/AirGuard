2. ปัญหา: เกณฑ์ตัวเลขแยกเหตุการณ์ไม่ออก

บทพูด · ผู้พูดแนะนำ: เปิด/ปิด (ทีมเลือก)

เครื่องวัดฝุ่นทั่วไปเตือนเมื่อค่าเกินเกณฑ์ เช่น PM2.5 เกิน 50
แต่สิ่งที่กระตุ้นอาการหลายครั้งไม่ได้ทำให้ค่าไหนเกินเกณฑ์ หรือขึ้นพอๆ กับเหตุการณ์ที่ไม่อันตราย
ลองดูสองกรณีนี้ ตอนทำอาหาร ฝุ่นขึ้น อุณหภูมิขึ้น ความชื้นขึ้นไปพร้อมกัน เพราะมีทั้งไอร้อนและไอน้ำ
ส่วนตอนปัดฝุ่นหรือราฟุ้ง ฝุ่นขึ้นอย่างเดียว อีกสองค่านิ่ง
ค่า PM2.5 ของสองกรณีอาจเท่ากันได้ เกณฑ์ตัวเดียวจึงแยกไม่ออก
แต่ถ้าดูหลายค่าพร้อมกัน จะเห็นว่ากรณีที่สองความสัมพันธ์ระหว่างค่าขาดหายไป
นี่คือสมมติฐานที่งานนี้ตั้งใจทดสอบ ส่วนทดสอบได้แค่ไหน จะเล่าตรงๆ ตอนท้าย

  • เครื่องที่มีขายเตือนเมื่อค่าเกินเกณฑ์ แต่สิ่งกระตุ้นอาการหลายครั้งไม่ได้ทำให้ค่าไหนเกินเกณฑ์
  • ตัวอย่างนี้เป็นแนวคิด — บอกตรงๆ ว่าเป็นสมมติฐานที่งานนี้ทดสอบ ผลจริงอยู่สไลด์ 28 และข้อจำกัดสไลด์ 32
  • อย่าอ้างว่าแยกสองเหตุการณ์นี้ได้แล้ว — ยังไม่ได้ทดสอบบนข้อมูลจริง

9. Pull-up · pull-down · การปรับสัญญาณ

Circuit · Schematic · PCB · PCBA · เริ่ม 5:40 · ยาว 1:10 · 8.0 ตัวอักษร/วินาที
บทพูด · ผู้พูดแนะนำ: ฮาร์ดแวร์

การปรับสัญญาณ ปุ่มทั้งสามต่อลงกราวด์ กดแล้วเป็นศูนย์ บนบอร์ดไม่มี pull-up ภายนอก จึงต้องเปิด pull-up ภายในราว 45 กิโลโอห์ม
ร่วมกับ RC กรองเด้งที่มี time constant 4.52 มิลลิวินาที และ debounce ในซอฟต์แวร์อีก 50 มิลลิวินาที
บัส I²C เป็น open-drain ต้องมี pull-up เราใช้ 4.7 กิโลโอห์มภายนอกไป 3.3 โวลต์ และปิด pull-up ภายในเพราะอ่อนเกิน
ที่ gate ของ MOSFET ขับ buzzer มี pull-down 100 กิโลโอห์ม ตอนบูตที่ขายังลอย buzzer จะไม่ดังเอง แรงดัน gate ได้ 3.27 โวลต์ และมีไดโอด flyback กันแรงดันย้อน
ขา TX ไป ZE07 มีตัวต้านทาน 100 โอห์มจำกัดกระแส เพราะ ZE07 รับลอจิกได้แค่ 3.0 โวลต์
ส่วน LED ใช้ 220 โอห์ม ได้กระแสประมาณ 5.9 มิลลิแอมป์ ต่ำกว่าพิกัดขา

  • ปุ่ม: τ = (45 000 + 220) × 100 nF = 4.52 ms · ในโค้ด tasks_io.c:564 เปิด GPIO_PULLUP_ENABLE และจับขอบลง (NEGEDGE)
  • I²C: ปิด pull-up ภายใน (enable_internal_pullup = false) เพราะ 45 kΩ อ่อนเกินสำหรับ rise time และมี 4.7 kΩ ภายนอกแล้ว · ห้ามจ่ายโมดูลด้วย 5 V
  • Q1: VGS(on) = 3.3 × 100k/101k = 3.27 V
  • R4: ไดโอดป้องกันของ ZE07 จะนำกระแส R4 จำกัดไว้ราว 3 mA
  • ถูกถาม "ทำไมปุ่มใช้ pull-up?" → ปุ่มต่อลงกราวด์ กดแล้วเป็น 0 จับขอบลง
  • ถูกถาม "R10 มีไว้ทำอะไร?" → pull-down ที่ gate ของ Q1 กัน buzzer ดังเองตอนบูต
