## วิธีสั่งงาน

วางข้อความนี้ให้ agent แล้วเปลี่ยนชื่อไฟล์งาน:

```text
อ่าน AGENTS.md และ CLAUDE.md ทั้งไฟล์ก่อน แล้วทำงานตาม docs/tasks/FW-1.md
ทำเฉพาะสิ่งที่อยู่ในไฟล์งานนั้น ห้ามทำงานถัดไปเอง
สร้าง branch ตามที่ระบุในไฟล์งาน commit ในเครื่องเท่านั้น ห้าม git push ห้ามเปิด PR ห้ามแตะ main
จบแล้วรายงานตามหัวข้อ "รายงานเมื่อจบงาน" ใน AGENTS.md
```

## วิธีรีวิว — ใช้ Claude Code **คนละ session** กับตัวที่สั่ง agent

ตัวที่สั่งงานรู้ว่าตั้งใจให้ออกมาเป็นยังไง จะมองข้ามจุดเดียวกับที่ agent พลาด → เปิด session ใหม่เพื่อรีวิวเท่านั้น

```text
คุณคือผู้รีวิว ห้ามแก้โค้ด ห้าม commit ห้าม push
อ่าน AGENTS.md, CLAUDE.md และ docs/tasks/<งาน>.md
1) git diff main...<branch> แล้วตรวจกับ "ข้อกำหนด" และ "ห้าม" ของงานทีละข้อ
2) รันทุกคำสั่งใน "เกณฑ์ผ่าน" เอง แปะผลจริง
3) เฟิร์มแวร์ตรวจเพิ่ม: esp_err_t ที่ไม่เช็ค · งานหนักหรือ log ใน ISR ·
   ตัวแปรที่ ISR/timer กับ task ใช้ร่วมกันโดยไม่ป้องกัน · stack ที่ไม่มีที่มา · blocking ที่ไม่ตั้งใจ ·
   เลข GPIO นอก board_pins.h · ขาที่ไม่อยู่ใน CLAUDE.md §4
4) ML ตรวจเพิ่ม: สุ่มแบ่งข้อมูล · normalizer แตะ val/test · accuracy · point adjustment · seed หาย
5) สรุปเป็น ✅ ผ่าน / ❌ ต้องแก้ (ระบุไฟล์:บรรทัด และเหตุผลเชิงกลไก) / ⚠️ ทดสอบบนบอร์ดเท่านั้นที่จะรู้
```

ผ่านแล้วคนเป็นผู้ `git push -u origin <branch>` → เปิด PR → merge

## ลำดับงาน

### 🎯 ชุด logger — เป้าหมาย: flash ลงบอร์ดได้ภายใน **จ. 5 ต.ค. 2569**

ข้อมูลปกติต้องเก็บ ≥ 3 วันต่อเนื่องก่อนสร้าง anomaly (`data/README.md`) → ทุกวันที่ logger ช้า = ข้อมูลหาย

| งาน | เนื้อหา | ต้องรอ | สถานะ |
|---|---|---|---|
| [FW-1](FW-1.md) | โครง ESP-IDF + LED · buzzer · ปุ่ม (ISR → queue) | — | ⬜ |
| FW-2 | `components/pms7003/` parser เฟรม (pure C) + host test | FW-1 | ⬜ เขียนโจทย์หลังรีวิว FW-1 |
| FW-3 | `components/storage/` จัดรูปแถว CSV ตาม §7 (pure C) + host test | FW-1 · 🔴 **ข้อตัดสินใจ D2** | ⬜ |
| FW-4 | ไดรเวอร์ UART (PMS7003) + I²C (BME280) + SPI (microSD) + ลูป 1 Hz + ปุ่ม MARK | FW-2 · FW-3 · 🔴 **D1** | ⬜ |

> BME280 อยู่ในชุด logger เพราะไอเดียหลักของโปรเจกต์ (§1) ต้องมี PM **คู่กับ** อุณหภูมิ/ความชื้น
> logger ที่มีแค่ PM เก็บข้อมูลไปก็พิสูจน์อะไรไม่ได้
